# simpomo

シンプルで軽量なポモドーロタイマーのデスクトップアプリ（Windows / macOS / Linux）。

画面の隅に小さく常駐し、基本は常に最前面に表示。ボタン一つで最前面モードを切り替えられます。
作業/休憩時間・サイクル数・通知音・ウィンドウサイズをカスタマイズ可能。
